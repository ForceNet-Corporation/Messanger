# Messanger

## Регистрация и Firebase Realtime Database

Регистрация сначала создаёт Firebase Auth-сессию, а затем записывает профиль и юзернейм в Realtime Database. Это важно для проектов, где правила RTDB требуют `auth != null`: прежняя версия пыталась резервировать юзернейм до авторизации и получала `permission_denied`.

Если после обновления появляется именно ошибка доступа к RTDB, проверьте Rules в Firebase Console. Минимальное требование для этой схемы — разрешать авторизованному пользователю создание/чтение собственного профиля и работу с `/usernames`. Не отключайте правила безопасности для всей базы.
